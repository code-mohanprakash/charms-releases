# Charms — downloads

Installers for **Charms**, a catalog of protective and good-fortune charms from cultures around the world.

**[Download the latest version](https://github.com/code-mohanprakash/charms-releases/releases/latest)**: `Charms-macOS.dmg` for Mac, `Charms-Windows-Setup.exe` for Windows.

The installers are free and not signed with a paid certificate, so your computer asks you to confirm the first time you open Charms:

- **Mac:** after the warning, open System Settings → Privacy & Security and click **Open Anyway**.
- **Windows:** on "Windows protected your PC", click **More info → Run anyway**.

This repository holds release files only. It contains no source code.
